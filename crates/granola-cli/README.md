# granola-cli

`granola-cli` provides the `granola` command-line tool for setting up and managing the Tailwind CSS and daisyUI build workflow in a Granola project without requiring Node.js or npm.

## Commands

### `granola init`

Scaffolds the project workflow by:

1. Creating the `dependencies/` directory to store downloaded binaries and plugin scripts.
2. Downloading the standalone `tailwindcss` Linux binary into `dependencies/` and verifying its SHA-256 checksum.
3. Downloading the standalone daisyUI plugin files (`daisyui.mjs` and `daisyui-theme.mjs`) into `dependencies/`.
4. Creating a default `input.css` configured to load daisyUI from `./dependencies/daisyui.mjs` and the scanner safelist from `./granola/safelist`.
5. Creating a default `build.rs` script that scans Rust source files with `granola-scanner`, writes `granola/safelist`, and invokes `dependencies/tailwindcss` during `cargo build`.
6. Adding `dependencies/`, `granola/`, and `output.css` to `.gitignore`.

### `granola update`

Checks GitHub releases for newer versions of Tailwind CSS and daisyUI, updating `dependencies/tailwindcss` and daisyUI plugin files if newer releases are available.

## Managed Files and Directories

Running `granola init` creates and manages the following project structure:

- `dependencies/`: Downloaded external tools and scripts (`tailwindcss`, `daisyui.mjs`, `daisyui-theme.mjs`).
- `granola/`: Intermediate outputs generated by Granola tooling (`safelist`).
- `input.css`: Tailwind entrypoint stylesheet importing daisyUI from `dependencies/` and referencing `granola/safelist`.
- `build.rs`: Cargo build script executing `granola_scanner` and `dependencies/tailwindcss` on `cargo build`.
- `.gitignore`: Updated to ignore `dependencies/`, `granola/`, and `output.css`.
